# Let's Go Home (letsgo.casa)

This is our project for UB Hacking 2026. Let's Go Home is a double opt-in game for seeing if your friend wants to leave an event without hurting their feelings. You both have the opportunity to let the server know you're ready to go home, and the server only reveals if the other person wants to leave once you both independently agree.

## Installation

1. Clone the repo
2. To install express, run this command: `npm i`
3. To test the app, run this command: `npm start` then open [localhost:3000](http://localhost:3000/) in your browser.

Since the app uses broswer local storage keys, open another incognito tab to simulate a second client, or serve the app with ngrok or over your LAN to access it on a second device.

A deployed version will be availble during the hackathon at [letsgo.casa](https://letsgo.casa).
